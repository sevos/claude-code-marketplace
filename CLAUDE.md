# Project Configuration

## Project Management

**System**: GitHub-Issues

This project uses GitHub Issues for ticket management. The repository is automatically detected from the git remote origin (sevos/claude-code-marketplace).

**Conventions**:
- Use `status:*` labels for workflow states (status:backlog, status:in-progress, status:review, status:done)
- Use `type:*` labels for issue types (type:feature, type:bug, type:enhancement)
- Use `estimate:*` labels for story points
- Use task lists in issue bodies for epic breakdown
- Use `## Dependencies` sections in issue bodies for blocks/blocked-by relationships
