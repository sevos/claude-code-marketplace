## Pronunciation Guide

Tolkien based Sindarin's phonology on Literary Welsh. Here are the key pronunciation rules:

### Vowels

| Letter | Sound | Example |
|--------|-------|---------|
| **a** | "ah" as in "father" | *adar* (AH-dar) |
| **e** | "eh" as in "pet" | *edhel* (EH-dhel) |
| **i** | "ee" as in "machine" | *min* (meen) |
| **o** | "oh" as in "note" | *morn* (mohrn) |
| **u** | "oo" as in "brute" | *dun* (doon) |
| **y** | French "u" or German "u" - say "ee" with rounded lips | *eryn* |

### Long Vowels (Accented)

- **Acute accent** (a, e, i, o, u, y): held slightly longer
- **Circumflex** (a, e, i, o, u, y): held even longer, mostly in monosyllables

### Diphthongs

| Diphthong | Sound | Example |
|-----------|-------|---------|
| **ai** | as in "rye" | *edain* |
| **ei** | as in "grey" | *eithel* |
| **ui** | as in "ruin" | *huin* |
| **au/aw** | as in "loud, how" | *naur* |
| **ae** | blended "AH-eh" | *maer* |
| **oe** | blended "OH-eh" | |

### Consonants

| Letter | Sound | Notes |
|--------|-------|-------|
| **c** | always hard "k" | *Celeborn* = "KEL-eh-born" (never "Sel-") |
| **g** | always hard as in "garden" | never soft as in "gin" |
| **th** | voiceless as in "thin" | never as in "that" |
| **dh** | voiced as in "that" | |
| **f** | "f" normally, "v" at end of words | *Nindalf* = "NIN-dalv" |
| **r** | rolled, as in Spanish or Italian | |
| **hw** | like English "wh" | |
| **lh** | voiceless "l", like Welsh "ll" | |
| **rh** | voiceless "r" | |

**Note:** Initial "i" before another vowel is pronounced like "y": *iant* (bridge) = "yant"

### Common Verbs

| English | Sindarin | Notes |
|---------|----------|-------|
| come | tol- | present: tol |
| speak/say | ped- | present: bed (lenited) |
| see | cen- | I-stem verb |
| give | anna- | past: on |
| do/make | car- | past: agor |
| write | teitha- | derived verb |
| listen | lasta- | imperative: lasto! |
| open | edra- | imperative: edro! |
| sleep | losta- | imperative: losto! |
| live | cuia- | imperative: cuio! |
| have | gara- | imperative: garo! |

**Verb Classes:** Sindarin has two main verb types:
- **Basic (I-stem)**: stem ends in consonant, e.g., *ped-* "to speak"
- **Derived (A-stem)**: stem ends in -a, e.g., *teitha-* "to write"

## Notes on Usage

### Historical Context

Tolkien developed Sindarin over many decades, with the language evolving significantly. Words from different periods may not be compatible:

- **Gnomish** (1910s): Earliest form
- **Noldorin** (1930s-1940s): Intermediate form
- **Sindarin** (1950s-1973): Final form used in published works

### Neo-Sindarin

Due to limited attested vocabulary, fans have extended Sindarin using:
- Words from earlier language stages (Noldorin, Gnomish)
- Reconstructions based on known etymological patterns
- Adaptations from Quenya cognates

When using Sindarin creatively, be aware that not all words are directly attested by Tolkien.

### Mutation

Sindarin features consonant mutations similar to Welsh. Initial consonants change based on grammatical context (soft mutation, nasal mutation, etc.). This affects adjectives after nouns, objects after verbs, and other situations.
